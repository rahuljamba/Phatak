Architecture Philosophy

Why WebSocket-First? No Push Notifications Needed.

Traditional APNs / FCM push notifications suffer from unpredictable network delivery delays, payload restrictions, and battery drain. Phatak Punjab uses direct persistent WebSockets for live road telemetry.

⚡

Zero Push Delays

Sub-second status synchronization as trains enter block sections. Drivers receive gate drop warnings before sirens finish sounding.

🔋

Battery & Foreground Efficient

Connects on-demand when user is actively monitoring crossings or in navigation mode. Consumes zero background battery quota.

☁️

Render.yaml Deploy Ready

Pre-configured with render.yaml, uvicorn, and production-grade ASGI concurrency ready for instant global hosting.
